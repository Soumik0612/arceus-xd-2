## ⚡ Highlights

- **Multi-Device Baileys Engine:** Fast, persistent session management with zero session disconnections.
- **8-Digit Pairing Code:** Pair directly without scanning QR codes on desktop or phone.
- **300+ Modular Commands:** Categorized into 21 high-powered packages (`GEN-CMD`, `AI-CMD`, `ADM-CMD`, `OWN-CMD`, `MEDIA-CMD`, `SPORT-CMD`, `MAKER-CMD`, etc.).
- **Group Armor & Automation:** Anti-Link, Anti-Badword, Anti-Bot, Anti-Foreign, Warn Threshold (1-5), and Auto Welcome/Goodbye.
- **AI Suite:** Integrated Gemini, GPT-4o, Claude, Meta AI, Mistral, and O3 reasoning models.

## 🚀 Quick Start (Node.js 20 & 24)

### 1. Clone the Repository
```bash
git clone https://github.com/arceus-dev/Arceus-XD.git
cd Arceus-XD
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment
```bash
cp .env.example .env
```

### 4. Run with Pairing Code
```bash
npm start
```
